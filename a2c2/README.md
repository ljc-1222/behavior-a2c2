# A2C2 implementation

This directory contains the multimodal residual-correction model, aligned episode loader, loss ablations, and training/evaluation entrypoints for OpenPI-Comet on BEHAVIOR-1K.

- [`src/`](src): model, data loading, losses, and online correction wrapper.
- [`scripts/`](scripts): dataset export, RGB feature conversion, training, offline evaluation, and serving.

See the [project overview](../README.md), [method](../docs/method.md), [evaluation diagnostics](../docs/results.md), [setup and usage](../docs/usage.md), and [fork integration](../docs/integration.md).
